# QQ / NapCat 崩了怎么修（2026-11-20 小鱼整理，谁接手都能用）

## 症状
- 我或小鲸的 QQ 收不到消息、发不出去
- QQ 弹「文件已损坏，请重新安装」

## 根因（今天验证过）
QQ 后台自动升级，把 NapCat 注入时替换过的文件又换回去了。注入一没，OneBot 的 HTTP 端口就没在听，桥拿不到东西。

## 账号与端口
- 1814620471 zp小鱼（我）：NapCat 目录 `C:\Users\w2423\dsh-tools\NapCat.Shell`，OneBot HTTP **3000**
- 3011565703 zp鱼鱼鱼（小鲸）：NapCat 目录 `C:\Users\w2423\dsh-tools\NapCat2`，OneBot HTTP **3011**
- 两个 OneBot 的 token 都是 `v6C8SpEh4FR67xo3`

## 判断步骤（按顺序，别跳）
1. `Test-NetConnection 127.0.0.1 -Port 3000`（或 3011）→ False 就是它的 NapCat 没起来
2. 看 `NapCat.Shell\logs`：**空的**说明根本没注入（不是配置错）
3. 看 QQ 版本：`(Get-Item 'C:\Program Files\Tencent\QQNT\QQ.exe').VersionInfo.ProductVersion`
4. 确认登录号：`curl 127.0.0.1:3000/get_login_info` 带 token

## 修法
1. 完全退出已经在跑的 QQ 和 NapCat（普通 QQ 必须先退，否则注入不上）
2. **右键 → 以管理员身份运行** 对应 launcher：
   - 我：`C:\Users\w2423\dsh-tools\NapCat.Shell\launcher.bat`
   - 小鲸：`C:\Users\w2423\dsh-tools\NapCat2\run-whale-qq.bat`（这个是我写的包装，里面写死了 `-q 3011565703`，双击即可，不用打命令）
3. 起来后验证端口 → True 就通了
4. QQ 设置里把**自动更新关掉**，不然还会重来

## 注意
- 非管理员杀不掉 NapCat 起的进程，也建不了 `/RL HIGHEST` 计划任务——这步只能本人点
- 新设备登录后头一两分钟，QQ 那边可能延迟/不显示刚发的消息，别急着判定失败
- 两个号各自独立：修一个不影响另一个，但都要各自以管理员启动一次
